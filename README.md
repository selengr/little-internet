# Little Internet

A small corner of the web.

Books, space, languages, maps, markets, photos, poems — little tools that feel alive. Built by Reza.

## Run it

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What’s here

Whatever’s useful and fun to poke at — dictionaries, books, countries, crypto, poetry, and more. Things change. Come back tomorrow.
